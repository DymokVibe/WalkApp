# LoopWalk

Минималистичное Android-приложение (Kotlin + Jetpack Compose) для ежедневных круговых прогулок без телеметрии, регистрации и платных API.

## Возможности
- Генерация замкнутого пешеходного маршрута от текущей точки по **времени (мин)**, **дистанции (км)** или **шагам**.
- Выбор характера маршрута через открытый роутер Valhalla (OpenStreetMap): **Парк / Тропы**, **Улицы / Асфальт**, **Вечер / Фонари** (`use_lit`).
- Пошаговые подсказки поворотов на экране и деликатная вибро-индикация за 30 м до поворота.
- **Сигнальные маяки** вдоль маршрута (+35 XP за прохождение точки).
- **Туман войны** (открытие секторов ~100x70 м) и **Захват контура** (расчёт площади замкнутого полигона прогулки).
- Уровни, ранги, серия дней (Streak), Крио-щиты, ежедневные модификаторы и достижения.
- Фоновый GPS-сервис (`ForegroundService`), аппаратный шагомер (`TYPE_STEP_COUNTER`) и экспорт трека в `.gpx`.

## Сборка APK через GitHub Actions
1. Создай новый репозиторий на GitHub и загрузи в него все файлы из архива.
2. Перейди во вкладку **Actions** -> **Build LoopWalk APK** -> скачай готовый артефакт `LoopWalk-debug`.
