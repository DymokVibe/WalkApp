# LoopWalk (v1.5)

Минималистичное AMOLED-приложение (Kotlin + Jetpack Compose + OSMDroid) для ежедневных круговых прогулок с пошаговым пешеходным навигатором без телеметрии, регистрации и платных API.

## Что исправлено и улучшено в v1.5
- **Оптимизация рендера карты и компаса**: вращение карты в режиме «КУРС» (Heading-Up) работает напрямую через `MapView` без пересборки Compose-дерева на каждом тике датчика; кэшированы полигоны «Тумана войны», добавлено автоматическое отключение автоследования при ручном перетаскивании карты пальцем, а также `onResume`/`onPause` для `MapView` при блокировке экрана.
- **Защита от перескока на обратный участок петли**: проекция на трек использует скользящее окно вперед по маршруту, исключая ложное прилипание к финишу в начале круга.
- **Корректная озвучка старта и учет паузы**: `WalkVoiceGuide` ставит первую фразу в очередь до завершения асинхронной инициализации Android TTS, а шагомер `TYPE_STEP_COUNTER` игнорирует шаги во время паузы.
- **Безопасная остановка сервиса и AMOLED-тема**: исправлена остановка `WalkTrackingService` через `stopService()`, добавлена `darkColorScheme` (читаемый ввод в настройках) и принудительные светлые системные иконки статус-бара.
- **Больше удобства в пути**:
  - Кнопка **«ДОМОЙ»** во время прогулки — мгновенно перестраивает кратчайший пешеходный путь к точке старта.
  - Интерактивный список поворотов — нажатие на любой маневр в списке фокусирует карту на этом перекрестке.
  - Индикатор точности GPS (`GPS ±Xм`) в верхней панели и автосохранение выбранного режима, профиля и дистанции.

## Сборка APK через GitHub Actions
1. Загрузи содержимое архива в репозиторий на GitHub.
2. Открой вкладку **Actions** -> **Build LoopWalk APK** -> скачай артефакт `LoopWalk-debug`.
