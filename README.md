# LoopWalk (v1.3)

Минималистичное AMOLED-приложение (Kotlin + Jetpack Compose + OSMDroid) для ежедневных круговых прогулок без телеметрии, регистрации и платных API.

## Что нового в v1.3
- **Многослойный неоновый маршрут**: светящаяся подложка, тёмная контрастная обводка и яркое ядро трека с округлыми стыками.
- **Навигационные стрелки и километровые метки**: шевроны направления движения прямо по линии круга и компактные плашки дистанции (`0.5 км`, `1.0 км` и т.д.).
- **Кастомные AMOLED-метки и тёмные карточки**: векторные иконки радара позиции, точки старта «ДОМ», сигнальных маяков с зоной захвата 35 м, точки следующего поворота и цели направления.
- **Выбор направления по карте (Long-Press)**: долгое нажатие в любую точку карты ставит якорь направления — маршрут строится в сторону выбранного парка или района и возвращает домой.
- **Полноэкранный интерфейс (Edge-to-Edge)**: верхний HUD, плавающие кнопки управления картой (центрирование, обзор всего круга, сброс якоря) и единая шторка профиля, журнала и калибровки.

## Сборка APK через GitHub Actions
1. Загрузи содержимое архива в репозиторий на GitHub.
2. Открой вкладку **Actions** -> **Build LoopWalk APK** -> скачай артефакт `LoopWalk-debug`.
